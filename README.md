# Tornado

Example [Tornado](https://www.tornadoweb.org/) app. Tornado is a Python web framework and asynchronous networking library.

## Deploy settings

| Field | Value |
| --- | --- |
| Build | Railpack |
| Project directory | `/` |
| Install command | leave empty |
| Build command | leave empty |
| Start command | leave empty |
| Application port | `8000` |
| Health check path | `/` |

## <a name="dev"></a>Run locally

```bash
# install dependencies
pip3 install -r requirements.txt

# start the app
python3 main.py
```

Requires Python 3.11 or later.
